# AI 控制的云计算

[English](guide.md) | 中文

## 变更

云原生开发现在仅提供连接和活动监控。手动提交命令及取回结果改由 `cloud_run` 与 `cloud_job` 完成 后者默认等待并收集 需要非阻塞查询时使用 `action: status`。AI 控制会校验创建任务的会话和工作区。

## 迁移

保留已有 GitHub 凭据和连接设置 在对话中要求 AI 执行计算任务。运行仓库留空时自动准备账号所属私有仓库。没有会话来源记录的既有任务仍可在 GitHub 查看 在工作会话中新建任务即可自动取回结果。显式认证 Remote 集成保留原有方法。
